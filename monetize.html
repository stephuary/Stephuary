Monetize · Phase 03

Make the offer clear enough to buy.

The point is not to describe everything you can do. The point is to define one offer that feels specific, credible, and easy to say yes to.

Output
One clear offer someone can repeat back correctly.
Test
One version you can put in front of a buyer immediately.
Next
Structure defines how this gets delivered, organized, and repeated.
Step 01

Buyer

Define exactly who this is for

Not a category. A situation. A person in a specific moment with a specific problem.

Not “founders.” Try “service founders who get interest but no committed buyers.”
What is happening right before they would buy this?
State the visible consequence, not a personality trait.
Step 02

Outcome

Define one result, not a bundle

This phase gets weaker the moment the result turns into a list.

One change they can picture. Not strategy, confidence, clarity, and momentum all at once.
Use one time frame the buyer can hold onto.
What can they now do that they could not do before?
Step 03

Delivery

Define the format and scope clearly

People trust offers that feel bounded.

Call the format exactly what it is.
What length of commitment is required?
Name the actual pieces, not vague process language.
Step 04

Pricing

Set one price and test whether it matches

A usable price is more valuable than a range you are afraid to say out loud.

Use one number. No range.
State the logic in one line.
This will build the offer, classify the type, and open the friction check.

    Step 05

    Friction

    Identify the weak point

    Do not fix everything. Find the first place the offer starts to wobble.

    Is the result specific enough to picture? The buyer should immediately understand what changes.
    Is the buyer situationally defined? This should feel like a real moment, not a broad audience label.
    Is the delivery clear enough to trust? The buyer should know what happens after paying.
    Does the price feel justified by the outcome? The number and the promise should feel proportionate.
    Does this sound like one offer? If it sounds like multiple offers collapsed together, it will create hesitation.
    Current friction read
    Complete the friction check to see where the offer is weakening.
    Step 06

    Offer versions

    Generate multiple usable versions

    Choose the version that gives you the cleanest test, not the most elaborate presentation.

    Version A
    Direct
    For warm outreach, DMs, emails, or actual conversations.
    Version B
    Premium
    For a private page, deck, or higher-trust environment.
    Version C
    Lower-friction
    For a smaller first yes when the full offer feels heavy.
    Version D
    Public post
    For testing the sentence in public without building a funnel first.
    Version E
    Waitlist / page
    For one page, one CTA, one source of traffic.
    Step 07
    Lock the offer. Route it forward.

    This offer now needs structure. Structure will define how it is delivered, organized, and repeated. If this still feels unclear, refine Monetize first. If it feels sharp enough to test, move it forward.
